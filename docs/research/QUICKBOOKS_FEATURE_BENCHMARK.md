## Vendor-Neutral Requirements Extracted (10–15 bullets)

*Requirements Innowit should implement regardless of QuickBooks specifics — derived from patterns above.*

1. **Batch-first transaction entry** — All high-volume entities (invoices, expenses, bills, journal entries) must support grid entry, CSV/Excel import, clipboard paste, and duplicate-with-modification.
2. **Recurring template engine** — Any transaction type can be templated with schedule (daily/weekly/monthly/custom), auto-post, auto-email, and reminder rules.
3. **Progress billing by phase/milestone** — Estimates/contracts decompose into phases; invoices generate from % complete or milestone triggers; deposits and retention supported.
4. **Approval workflow engine** — Visual rule builder (if/then), multi-level routing, delegation, SLA/escalation, execution audit log, task inbox with comments and entity links.
5. **Fine-grained RBAC with field-level policies** — Roles compose permissions (view/create/update/approve/post/transmit) per resource; field-level visibility/edit rules; report-level access; API enforcement.
6. **Custom field framework** — Typed fields (text/number/date/picklist/multi-select/attachment) attachable to any entity; searchable, reportable, migratable.
7. **Dimension system (classes/locations/departments/projects)** — Hierarchical dimensions; multi-dimension tagging on every transaction line; reporting group-by and budget-by-dimension.
8. **Custom report builder (metadata-driven)** — Drag-drop columns/filters/grouping/sorting/computed fields; save as template; export PDF/Excel/CSV; schedule email.
9. **Dashboard & KPI widgets with drill-through** — Widget library (KPI card, trend chart, variance bar, table); target setting; period comparison; click-through to underlying report.
10. **Budgeting & forecasting with scenarios** — Budget entry by dimension+period; budget-vs-actual reports; scenario engine (best/base/worst) with cash runway calculator.
11. **AI-assisted bookkeeping quality** — Continuous scans (duplicates, missing attachments, round numbers, unreconciled, anomalies); explainable suggestions; one-click corrections with approval.
12. **Finance AI chat (RAG over tenant data)** — Natural language queries answer with citations; action buttons (drill, create task, adjust); grounded in authorized data only.
13. **Spreadsheet sync (bidirectional)** — Excel add-in or file-based sync; templates; change detection; conflict resolution; multi-entity consolidation.
14. **Public API + webhooks + sandbox** — RESTful CRUD for all entities; OAuth2; webhook delivery with retry/signing; developer sandbox; rate limits documented.
15. **Automated backup + version history + PITR** — Daily snapshots + WAL; entity-level versioning; point-in-time restore with preview; immutable audit log of restores.
16. **Customer self-service portal** — Magic-link auth; view/pay invoices; approve estimates; sign contracts; document access; notification preferences.
17. **Accountant/read-only access** — Dedicated accountant role (read + adjusting entries); activity feed; shared reports without login sharing; audit trail segregation.
18. **Kenya eTIMS System-to-System integration** — Onboard, sign, submit, verify; buyer-initiated invoicing; stock management; reverse invoicing; control number on every invoice.
19. **Kenya payroll engine (versioned, effective-dated)** — PAYE/NSSF/SHIF/AHL as configurable rule sets; annual Finance Act updates via config (no code deploy); statutory reports (PAYE return, NSSF return, SHIF return).
20. **M-Pesa/bank reconciliation engine** — STK Push/B2C/B2B/PayBill/Till callbacks; reference-based auto-match; CSV import fallback; fee tracking; reversal handling; audit trail.
